# Goals

One file per project (`<line id>.md`), in Tarek's words. The rater treats these as the strongest source after a project's own `ROADMAP.md`:
the goal and the stations listed here are used as written; the rater plans the steps around them.
Lines under "Done (Tarek's word)" count as evidence, for milestones that no commit can show (a contract signed, a customer live).
