# Commandcenter

This repo runs Tarek's Commandcenter wall screen. `STANDARD.md` is the rulebook, `projects/<id>.md` holds each project's goal, route and steps.

Claude owns the project plans. When Tarek says something in this session about one of his projects (something is done, a new goal or feature, a changed order, a rule, or that a decision was wrong), update `projects/<id>.md` (or `PRIORITY.md`) in this session as `STANDARD.md` and step 1 of `WORKER.md` describe, add a decision line, commit and push to `main`. The repo is public: write only project-level results, never personal data.
